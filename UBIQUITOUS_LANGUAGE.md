# Context-selection language

- **Request view**: messages sent through DCP toward a provider. Transformations do not rewrite original session entries.
- **Result reference**: session ID, result-entry ID, tool-call ID and digest binding the original call arguments and persisted result.
- **Source observation**: an observed whole-file text read matching a bounded canonical allowlisted file; not attestation of an untrusted runtime.
- **Pin**: durable branch-local protection against DCP changes. Owner and compression-suspension reasons are independent. Pins do not prevent native Pi compaction.
- **Task revision**: the explicitly supplied scoring brief and its live validity. New input, task changes and lifecycle transitions invalidate decisions.
- **Shadow scoring**: collect judgments without authorizing omissions.
- **Restore**: protect an original pair already present in the active view. Suspended historical results are not automatically reinserted.
- **Recall**: explicitly append exact persisted text as labelled reference data on the current branch, without inserting an old tool result or starting a model turn.
- **Owner confirmation**: a native interactive control, not assistant/user-role text or an RPC dialog.
- **Estimated reduction**: request-view token estimates. Not measured billing, cache savings, accuracy or end-to-end latency.
